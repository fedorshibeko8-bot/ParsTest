# Запуск бота на Windows

Пошаговая инструкция для не-программиста. Всё делается на обычном ПК с
Windows 10/11. Сервер, VPS и systemd не нужны — это следующий этап.

Если что-то не получается, сначала загляните в раздел
[«Если что-то пошло не так»](#если-что-то-пошло-не-так): там почти все
ошибки разобраны.

---

## Что понадобится

- Windows 10 или 11, интернет.
- Telegram на телефоне или ПК.
- Аккаунт Google — для бесплатного ключа Gemini.
- Аккаунт Groq — для бесплатного запасного ключа.
- **VPN с зарубежным IP** — Gemini и Groq не работают с российских адресов.
  VPN нужен только в момент обращения к ИИ (нажатие «Доработать с ИИ»),
  для самого Telegram — нет.

---

## Шаг 1. Установить Python

1. Откройте <https://www.python.org/downloads/> и скачайте последнюю версию
   Python для Windows (нужна 3.11 или новее).
2. Запустите установщик. На первом экране **обязательно** поставьте галочку
   **Add Python to PATH**, затем нажмите **Install Now**.
3. Дождитесь окончания и закройте установщик.

Проверка: нажмите `Win+R`, введите `cmd`, нажмите Enter. В чёрном окне
наберите:

```
python --version
```

Должно появиться что-то вроде `Python 3.12.4`. Если пишет «не является
внутренней или внешней командой» — Python не попал в PATH, переустановите
его с галочкой.

---

## Шаг 2. Подготовить папку и установить зависимости

1. Скопируйте папку проекта (например, `ParsTest`) в удобное место, путь
   без сложных символов: `C:\ParsBot` подойдёт лучше, чем папка с
   кириллицей и пробелами.
2. Дважды щёлкните **`setup.bat`**.

Скрипт создаст `.venv` (отдельное окружение Python), установит библиотеки,
создаст `.env` из образца и папки `data`, `logs`. Первый запуск занимает
несколько минут — это нормально.

В конце будет написано «Готово».

---

## Шаг 3. Получить токен бота

1. В Telegram откройте **@BotFather**.
2. Отправьте `/newbot`.
3. Придумайте имя (например, `Pars GTA News`) и username, заканчивающийся
   на `bot` (например, `parsgta_bot`).
4. BotFather пришлёт строку вида
   `123456789:AAH...` — это **BOT_TOKEN**. Скопируйте её целиком.

Если бот уже создан, токен можно посмотреть так: `/mybots` → выбрать бота →
**API Token**.

---

## Шаг 4. Подготовить канал

1. Создайте канал или используйте существующий.
2. Добавьте бота в **администраторы** канала и включите право
   **Публикация сообщений** (остальные права не обязательны).
3. Запишите **CHANNEL_ID**:
   - если у канала есть публичный username (например, `@fowgsl`) — можно
     указать его прямо так: `CHANNEL_ID=@fowgsl`;
   - числовой ID вида `-1004371911262` тоже подходит. Узнать его можно,
     переслав любой пост из канала боту **@userinfobot** (он покажет
     `Forwarded from chat: -100...`) или через настройки канала.

---

## Шаг 5. Собрать ID администраторов

Каждый админ должен отправить боту любое сообщение (например, `/start`),
иначе бот не сможет присылать ему уведомления в личку.

Свой числовой ID узнаётся у **@userinfobot** (он отвечает строкой `Id: ...`).
Соберите ID всех админов через запятую, без пробелов:

```
ADMIN_IDS=7846135495,1389758957,1825876129
```

---

## Шаг 6. Получить бесплатные ключи ИИ

### Gemini (основной провайдер)

1. Откройте <https://aistudio.google.com/apikey> (нужен VPN).
2. Войдите в Google-аккаунт.
3. Нажмите **Create API key** и скопируйте ключ в `GEMINI_API_KEY`.

Бесплатного тарифа Flash-Lite хватает с большим запасом: бот делает один
запрос на нажатие «Доработать с ИИ».

### Groq (запасной провайдер)

1. Откройте <https://console.groq.com/keys> (нужен VPN).
2. Зарегистрируйтесь, создайте ключ и скопируйте его в `GROQ_API_KEY`.

Groq используется только если Gemini недоступен, вернул ошибку или
исчерпал лимит. Модель `openai/gpt-oss-120b` уже прописана по умолчанию.

> Ключи — это пароли. Не отправляйте их в чаты и не коммитьте в git.
> Файл `.env` в репозиторий не попадает.

---

## Шаг 7. Заполнить `.env`

Откройте файл `.env` в папке проекта Блокнотом (правая кнопка →
**Открыть с помощью** → **Блокнот**). Заполните как минимум:

| Переменная | Что вписать |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `CHANNEL_ID` | `@username` канала или числовой ID `-100...` |
| `ADMIN_IDS` | числовые ID админов через запятую |
| `GEMINI_API_KEY` | ключ Gemini |
| `GROQ_API_KEY` | ключ Groq |

Остальные значения можно не менять — они уже настроены под ТЗ:

| Переменная | Значение по умолчанию | Зачем |
|---|---|---|
| `DRY_RUN` | `1` | безопасный режим: без публикаций и без ИИ |
| `NEWS_KEYWORDS` | `GTA 6, GTA VI, Grand Theft Auto, Rockstar` | что считается «новостью по теме» |
| `POLL_INTERVAL_MIN_SEC` / `MAX_SEC` | `300` / `600` | как часто проверять сайты |
| `POST_TTL_HOURS` | `48` | сколько новость живёт в очереди |
| `INTERCEPT_TIMEOUT_MINUTES` | `10` | сколько админ может держать пост |
| `IMAGE_MAX_MB` | `10` | лимит картинки |
| `PUBLISH_SILENT` | `0` | `1` — публиковать без звука |

Сохраните файл (Ctrl+S) и закройте Блокнот.

---

## Шаг 8. Первый запуск — проверка без публикаций

Оставьте `DRY_RUN=1` и дважды щёлкните **`run.bat`**.

Что должно произойти:

1. В окне появятся сообщения о запуске, окно останется открытым.
2. В течение 5–10 минут бот проверит сайты и пришлёт админам в личку
   уведомление **без текста новости** с кнопкой «Взять инициативу».
   Если новостей нет — это нормально, просто подождите.
3. Нажмите кнопку. Придёт карточка: картинка (если была в ленте),
   заголовок и текст, кнопки меню.
4. Проверьте:
   - **✏️ Править вручную** → «Изменить текст», «Изменить картинку»,
     «Убрать картинку», «Назад»;
   - **🔗 Посмотреть источник** — ссылка приходит только вам в личку;
   - **🤖 Доработать с ИИ** — в `DRY_RUN` вернётся предсказуемый
     тестовый текст (ключи и VPN пока не нужны);
   - **🚀 Опубликовать** — в `DRY_RUN` пост помечается опубликованным,
     но в канал **ничего не уходит**;
   - **❌ Не публиковать** — пост снимается с очереди.
5. Если не трогать карточку 10 минут, пост вернётся в очередь и придёт
   уведомление всем админам.

На этом этапе в канал не должно уйти ни одного сообщения. Если ушло —
остановите бота (Ctrl+C) и напишите разработчику.

---

## Шаг 9. Боевой режим

1. Включите VPN с зарубежным IP.
2. В `.env` замените `DRY_RUN=1` на `DRY_RUN=0`. Сохраните.
3. Запустите `run.bat` заново.
4. Дождитесь новости, перехватите её, нажмите **🤖 Доработать с ИИ**,
   проверьте текст и нажмите **🚀 Опубликовать**.
5. Пост должен появиться в канале: картинка сверху, жирный заголовок,
   текст. Без ссылки на источник, хэштегов и подписи канала.

> Telegram и опрос сайтов работают и без VPN. VPN нужен только для
> запросов к Gemini/Groq. Если VPN выключен в момент нажатия кнопки,
> бот напишет, что ИИ недоступен, и пост останется у вас.

---

## Как это работает

1. Бот каждые 5–10 минут проверяет игровые ленты (VGC, IGN, Eurogamer,
   GamesRadar+, GameSpot).
2. Оставляет только новости по ключевым словам из `NEWS_KEYWORDS`.
3. Сравнивает заголовки с очередью и опубликованным за 7 дней: точный
   дубль пропускает молча, похожий (серая зона) показывает с пометкой.
4. Скачивает картинку и присылает админам уведомление с кнопкой.
5. Кто первый нажал — тот владелец поста на 10 минут. Любое действие
   продлевает таймер, бездействие возвращает пост в очередь.
6. Публикация — только по кнопке. Бот сам в канал ничего не пишет,
   служебные сообщения идут исключительно в личку админам.
7. Через 48 часов невостребованная новость снимается с очереди,
   а картинки завершённых постов удаляются с диска (запись в БД остаётся).

## Если что-то пошло не так

Сначала посмотрите `logs\bot.log` — там по-русски написана причина.
Окно `run.bat` при ошибке не закрывается, код ошибки тоже подсказывает.

| Что видите | Что делать |
|---|---|
| «Не найден Python 3.11» | Переустановите Python с галочкой **Add Python to PATH** |
| «Не задан BOT_TOKEN» | Заполните `BOT_TOKEN` в `.env`, сохраните файл |
| «Telegram отклонил BOT_TOKEN» | Скопируйте токен заново у @BotFather, без пробелов |
| «Не задан CHANNEL_ID» | Заполните `CHANNEL_ID` или верните `DRY_RUN=1` |
| «Бот не может писать в канал» | Добавьте бота админом канала с правом публикации |
| «админ N не активировал бота» в логе | Этот админ не нажал `/start` у бота — попросите |
| «ИИ недоступен… 403 / регион не поддерживается» | Включите VPN с зарубежным IP и нажмите кнопку ещё раз |
| «лимит запросов (429)» | Дождитесь суток или используйте запасной ключ; текст можно править вручную |
| Бот молчит, новостей нет | Это нормально: в лентах нет новостей по ключевым словам. Проверьте `logs\bot.log` |
| Окно закрылось сразу | Запускайте через `run.bat`, а не `python bot/main.py` |

Ничего не удаляйте в папках `data` и `logs`, пока не разберётесь: там
база, картинки и история.

## Автозапуск (необязательно)

Чтобы бот поднимался после перезагрузки:

1. Откройте **Планировщик задач** (в поиске Windows).
2. **Создать задачу** → вкладка **Действия** → **Создать**.
3. Действие: **Запуск программы**, программа — `C:\ParsBot\run.bat`
   (ваш путь), рабочая папка — папка проекта.
4. Вкладка **Условия** → снимите галочку «Выполнять только при питании
   от сети» (для ноутбука).
5. Вкладка **Триггеры** → «При входе в систему».

Бот будет работать в фоне без окна. Остановить — завершить задачу в
Планировщике или закрыть процесс `python.exe`.

## Обновление и резервные копии

- **Бэкапы.** Каждый запуск и далее раз в сутки бот делает снимок базы в
  `data\backups` и хранит 7 последних. Восстановление: остановить бота,
  заменить `data\bot.db` нужным снимком, запустить снова.
- **Обновление кода.** Остановите бота (Ctrl+C), замените файлы проекта,
  не трогая `.env` и папку `data`, запустите `setup.bat` (он доставит
  новые зависимости), затем `run.bat`.
- **Перенос на другой ПК.** Скопируйте всю папку, включая `.env` и `data`.
  Запустите `setup.bat` на новом месте — окружение создастся заново.

## Что дальше

Когда всё стабильно работает на ПК, можно переносить на хостинг
(Bothost): там базу и картинки нужно положить в `/app/data`, а в профиле
включить «Зарубежный IP для API и нейросетей» и задеплоить заново.
Инструкция появится отдельно, после проверки на ПК.
