# ParsTest

Telegram-бот для игрового канала: сам находит новости GTA 6 и игровой индустрии
в англоязычных лентах, показывает их админам, переписывает на русский через
бесплатный ИИ и публикует в канал после одобрения.

## Быстрый старт (Windows)

1. Установите Python 3.11+ (галочка **Add Python to PATH**).
2. Запустите `setup.bat` — он создаст окружение и файл `.env`.
3. Заполните `.env` (токен бота, канал, админы, ключи ИИ).
4. Запустите `run.bat`.

Подробная инструкция для не-программиста — в [ЗАПУСК.md](ЗАПУСК.md).

## Документация

- `ТЗ.md` — требования к боту.
- `TASKS.md` — план задач и статусы.
- `CHANGELOG.md` — что и когда сделано, решения и передача между задачами.

## Разработка

```bat
.venv\Scripts\python.exe -m pytest
.venv\Scripts\python.exe -m compileall -q bot
```
