# ТЗ: Telegram-бот для ведения игрового канала (GTA 6 / gaming news)

**Версия:** 1.0
**Дата:** 18 ноября 2026
**Статус:** согласовано, готово к реализации MVP

---

## 1. Суть проекта

Бот-помощник администраторов Telegram-канала: сам ищет новости на англоязычных игровых сайтах, отбирает подходящие по теме (игры, особенно GTA 6), даёт администраторам «взять инициативу» над новостью, помогает переписать текст через ИИ (опционально, по кнопке) и публикует в канал только после одобрения человеком.

Управление — полностью через Telegram-бота (личные сообщения админам).

---

## 2. Источники (MVP)

Список проверен на ноябрь 2026, все ленты рабочие и бесплатные.

| Сайт | RSS-лента |
|---|---|
| VGC (Video Games Chronicle) | `https://videogameschronicle.com/feed/` |
| IGN (games) | `https://feeds.feedburner.com/ign/games-all` |

**Правила опроса:**

- Запасные источники на будущее: PC Gamer, Kotaku, Dexerto, Insider Gaming.

## 3. Отбор новостей по теме

Только логика бота, без LLM.

- Проверяются **заголовок** и **лид** (первые ~200 символов текста ленты).
- Ключевые слова (конфигурируемый список): «GTA 6», «GTA VI», «Grand Theft Auto», «Rockstar» + общие игровые ключи.
- Найденная новость проходит дедупликацию (п. 4) и попадает в очередь.

---

## 4. Дедупликация (без LLM)

Три ступени, от дешёвой к дорогой:

1. **URL/GUID**: сравнение с таблицей всех уже виденных ссылок в SQLite. Совпадение — молча пропускаем.
2. **Строковое сравнение заголовков** (нормализация: нижний регистр, без пунктуации и стоп-слов; `difflib.SequenceMatcher`):
   - схожесть **≥ 0.85** — дубль, молча пропускаем;
   - **0.70–0.85** — «серая зона»: показываем админу с пометкой «⚠️ похоже на уже опубликованное/найденное» (решение принимает человек);
   - **< 0.70** — новая новость.
3. **Сравнение с историей**: профиль pending + published за последние 7 дней.

Все «серые зоны» пишутся в лог — для настройки порога в дальнейшем.

**Отложено на второй этап:** эмбеддинги (Gemini Embedding 2) и LLM-суждение для спорных случаев.

---

## 5. Жизненный цикл поста

```
pending ──→ intercepted ──→ published
   │            │
   └────────────┴────────→ dropped
```

- **pending** — в очереди, доступен к перехвату.
- **intercepted** — взят админом (храним кто и когда).
- **published** — опубликован в канал.
- **dropped** — отказ админа, тайм-аут или истёк TTL.

**TTL для pending: 48 часов.** После — автоматически `dropped`.

**Картинки:**
- Скачиваются в **момент обнаружения** новости (а не при перехвате) — чтобы не потерять при «протухшей» ссылке и чтобы карточка открывалась мгновенно.
- Удаляются с диска при переходе поста в `dropped`/`published` через 48 часов.

**Очередь:**
- Видимых pending — до 10 самых свежих.
- Уведомления уходят по самому старому посту первым (FIFO).

---

## 6. Уведомления (личные сообщения)

- Каждый админ получает уведомление в личку: **«Найдена новость»** — **без контента**, только сигнал и кнопка «Взять инициативу».
- Админ, у которого уже есть активный пост, новых уведомлений не получает (нельзя работать над двумя постами).
- При перехвате остальные получают сообщение: «Пост #N взял админ X».
- Пустая очередь → следующая находка анонсируется мгновенно.

---

## 7. Перехват и тайм-аут

- Инлайн-кнопка **«Взять инициативу»**; первый нажавший становится владельцем поста.
- **Тайм-аут: 10 минут бездействия.** По истечении: уведомление всем админам, пост возвращается в очередь, перехват снова доступен всем.
- Любое действие владельца (нажатие кнопки, отправка текста, отправка фото) сбрасывает таймер.

---

## 8. Меню владельца (после перехвата)

Отображается карточка: картинка + оригинальный заголовок + лид, и кнопки:

```
[🚀 Опубликовать]        [🤖 Доработать с ИИ]
[✏️ Править вручную]     [❌ Не публиковать]
[🔗 Посмотреть источник]  ← только админу, в канал не попадает
```

**«Править вручную»** открывает подменю:
- ✏️ Изменить текст — админ присылает новый текст сообщением;
- 🖼 Изменить картинку — админ присылает новое фото (лимит Telegram: 10 МБ);
- 🚫 Убрать картинку;
- ↩ Назад — в основное меню.

Каждое действие возвращает к предпросмотру поста с обновлённым меню.

---

## 9. ИИ — только рерайт

- **Провайдер:** Gemini Flash-Lite (бесплатный тариф, 500 запросов/день), фоллбэк — Groq `gpt-oss-120b` (1000 запросов/день).
- **1-й вызов:** полный текст статьи → выжимка.
- **2-й и последующие вызовы:** полный текст статьи + текущий черновик + инструкция. Источник истины всегда — оригинальная статья, не предыдущая выжимка (защита от дрейфа и галлюцинаций).
- Промпт обязывает: перевести на русский, переписать своими словами, не добавлять факты, которых нет в статье; заголовок 40–70 символов, тело 120–350 символов.
- **Счётчик кругов:** после 3–4 проходов бот подсказывает «текст уже сильно отработан, дальше лучше править вручную».
- История версий черновика хранится в БД (возможность отката).
- Запрещено использовать ИИ для: фильтрации новостей, дедупликации, финальной проверки фактов.

---

## 10. Шаблон публикации

- **Картинка сверху** + подпись (если картинки нет — текстовый пост).
- **Заголовок жирным: 40–70 символов** (с пробелами).
- **Тело: 3–5 × длина заголовка = ~120–350 символов.**
- Итого пост: **160–420 символов** (короткий формат, «заголовок + пара предложений»).
- **Ссылок на источник в посте нет.** URL хранится только в БД и доступен админу по кнопке.
- Хэштеги и подпись канала по умолчанию отсутствуют (обсуждаются отдельно).
- **Публикация мгновенная** по нажатию кнопки.

## 11. Администраторы

- Список — числовые Telegram ID в конфиге `.env`.
- Изменение списка — редактированием конфига и перезапуском.
- Бот имеет права администратора в канале (публикация сообщений); уведомления шлёт в личку.

## 12. Инфраструктура и сервер

| Компонент | Решение |
|---|---|
| Язык / фреймворк | Python + aiogram |
| БД | SQLite (файл на диске) |
| Соединение с Telegram | long polling (домен и SSL не нужны) |
| Автозапуск | systemd |
| Секреты | `.env` (токены, ID админов) |
| Логи | текстовые, ротация по дням, хранение 30 дней |
| Бэкап | SQLite раз в сутки |
| LLM | Gemini Flash-Lite → Groq (fallback) |
| Старт | бесплатный Bothost (~256 МБ RAM) |
| Запасной вариант | VPS 99–150 ₽/мес, Европа |

**Оценка нагрузки:** Python-процесс ~100–150 МБ RAM; SQLite — мегабайты; CPU и трафик минимальны (десятки RSS-запросов в час). В бесплатный тариф влезаем, но без запаса — при потреблении > 200 МБ переезд на VPS.

**Бюджет:** ~150 ₽/мес максимум (или 0 ₽ на бесплатном хостинге); LLM и API — бесплатные тарифы.

---

## 13. План работ (MVP)

1. Скелет бота: конфиг, `.env`, список админов, подключение к каналу.
2. Парсер RSS + фильтр по ключам + дедупликация ступеней 1–2.
3. Очередь, уведомления, перехват, блокировки, тайм-ауты (10 мин), TTL (48 ч).
4. Карточка поста, меню, ручная правка текста и картинки.
5. Интеграция Gemini: рерайт с якорем на статью, счётчик кругов, фоллбэк Groq.
6. Публикация в канал по шаблону.
7. Деплой на сервер, мониторинг, бэкап.
